# Batara Parkview — Official Website

Website resmi perumahan **Batara Parkview** oleh **Badak Perkasa Group (BPG)**. Menampilkan informasi perumahan modern, pilihan tipe rumah (Krisan, Amarilys, Daisy, Kalmia), fasilitas kawasan, kalkulator KPR, dan formulir konsultasi cepat.

## 🏠 Halaman & Struktur
- `index.html`: Beranda utama (Hero, Keunggulan TOD Cikoya, Type Rumah, Formulir Brosur, Lokasi & Testimoni).
- `tentang-kami.html`: Profil developer BPG, filosofi, master plan kawasan, dan fasilitas lengkap.
- `tipe-rumah.html`: Katalog lengkap seluruh tipe unit rumah beserta denah dan spesifikasi teknis.
- `artikel.html`: Portal tips properti, finansial, dan panduan membeli rumah pertama.
- `artikel-detail.html`: Halaman baca artikel lengkap dengan konten edukasi.
- `404.html`: Halaman error kustom dengan navigasi kembali ke beranda.

## 🚀 Teknologi
- **HTML5 & Semantic Elements**
- **Tailwind CSS & Custom Design System** (Font Syne & Poppins)
- **Vanilla JavaScript** (Interaksi modal promo, denah rumah, filter tipe, floating WA)
- **Netlify Ready** (Konfigurasi otomatis melalui `netlify.toml`)

## 🌐 Deploy di Netlify
Website ini adalah static website murni yang siap dideploy langsung di Netlify:
1. Hubungkan repository GitHub ini ke [Netlify](https://app.netlify.com).
2. Konfigurasi build otomatis terbaca dari `netlify.toml`:
   - **Publish directory**: `.` (root)
   - **Build command**: *(kosong)*
3. Klik **Deploy site**.
